# EVIDENCE / PASS POLICY

STATUS: NORMATIVE

A declaration is not evidence.

PASS requires current evidence tied to the active stage and current repository state. As applicable capture:
- before-state;
- recovery path;
- changed-file inventory;
- diff/compare;
- type/lint/build tests;
- semantic checks;
- public-truth checks;
- accessibility/performance/security checks;
- after-state identity.

Historical PASS does not prove current state. Missing material verification => NOT_SAFELY_TESTABLE, not PASS.
