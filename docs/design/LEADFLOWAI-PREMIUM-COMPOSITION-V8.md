# LEADFLOWAI — PREMIUM COMPOSITION V8

STATUS: OWNER-APPROVED IMPLEMENTATION DIRECTION
DATE: 2026-08-13

## Intent
V8 removes the repeated-template feel from the homepage without replacing the already approved visual foundation.

## Authority boundaries
- V5 remains authoritative for the realistic motherboard photograph, water interaction and WebGL performance bounds.
- V6 remains authoritative for restrained technical frames and compact section labels.
- V7 remains authoritative for Live Lab, live 3D, interactive proofs and the expanded 3D / interactive / motion / AI offer.
- V8 supersedes prior versions only for homepage composition, stage art direction, hero depth and cross-stage visual continuity.

## Required changes
1. CREATE, DISCOVER, CONVERT, INTELLIGENCE, CONNECT and CARE may not render as six copies of one text panel.
2. Each stage must have a distinct live browser-native visual matched to its semantic purpose.
3. Stage composition alternates between copy-first and visual-first layouts on desktop.
4. Stage height must be materially tighter than V6 to reduce dead space while preserving readable spacing.
5. Stage headings use a controlled two-part hierarchy with a quieter secondary phrase instead of oversized four-line text blocks.
6. A single vertical system spine links stages 01–06 and indicates the current stage during scroll.
7. Hardware-UI details include active corner markers, bounded status labels, signal lines and restrained glow.
8. Background lighting may be locally shaped per stage, but the underlying V5 motherboard photograph must remain unchanged.
9. Hero gains restrained pointer depth/parallax and layered system planes without adding a heavyweight 3D dependency.
10. Existing V7 live experience modules remain available and must not be degraded.

## Stage visual semantics
- CREATE: browser/UI composition plus production-code representation.
- DISCOVER: search architecture / entity / schema relationship map.
- CONVERT: intent-to-action conversion path and funnel.
- INTELLIGENCE: controlled AI / RAG / context network.
- CONNECT: website hub with modular API / CRM / mail / calendar / data endpoints.
- CARE: monitoring / performance / search health / security / iteration dashboard.

## Public truth
The stage visuals are first-party interface demonstrations, not customer metrics or customer case studies. Status text is qualitative UI language and must not fabricate business results.

## Performance
- no new third-party 3D library;
- no new global WebGL context;
- stage visuals use DOM/CSS/SVG and bounded IntersectionObserver behavior;
- no scroll event loop;
- continuous decorative animations stop under `prefers-reduced-motion`;
- mobile removes the system spine and simplifies dense visual details.

## Exit criteria
PASS requires typecheck, lint, full repository verification, static export contract, route smoke tests and exact V8 design-contract validation.
