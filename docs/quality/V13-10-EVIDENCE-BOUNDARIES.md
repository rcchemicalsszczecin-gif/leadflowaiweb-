# V13.10 — Evidence boundaries

STATUS: ACTIVE RELEASE BOUNDARY

## Local SEO / Szczecin

- `/local-seo` może opisywać Szczecin jako przykład realnego obszaru działalności klienta.
- V13 nie publikuje niepotwierdzonego adresu, NAP ani twierdzenia, że LeadFlowAI posiada fizyczną lokalizację w Szczecinie.
- Nie tworzymy kopii stron dla dzielnic/miast bez unikalnej, rzeczywistej lokalnej wartości.
- Konkretne dane lokalizacji LeadFlowAI mogą wejść do schema i publicznego UI dopiero po zatwierdzeniu public truth / final legal identifiers.

## Original research / własne dane

Workstream 59 jest **EVIDENCE-DEFERRED do V13.11**, a nie pominięty.

Nie wolno publikować jako „badanie LeadFlowAI”:
- wymyślonej próby stron,
- syntetycznych KPI udających pomiar rynku,
- fikcyjnych średnich Core Web Vitals,
- nieudokumentowanych udziałów technologii lub błędów,
- raportu bez daty, metodologii i źródłowego datasetu.

Pierwszy materiał original research może zostać opublikowany dopiero po zebraniu realnego datasetu. Minimalny kontrakt badania:
1. jawny zakres i pytanie badawcze;
2. data lub okres zbierania danych;
3. kryteria doboru próby;
4. lista źródeł lub możliwy do audytu sposób ich pozyskania;
5. metodologia pomiaru i definicje metryk;
6. rozdzielenie obserwacji od interpretacji;
7. możliwość odtworzenia obliczeń;
8. publiczny disclaimer ograniczeń badania.

## V13 release decision

Brak fikcyjnego raportu jest warunkiem PASS, nie brakiem jakości. V13 może wejść do final acceptance bez original research, jeżeli:
- strona nie twierdzi, że takie badanie już istnieje;
- V13.11 zachowuje research jako post-release authority-growth track;
- przyszłe dane przejdą evidence/public-truth review przed publikacją.
