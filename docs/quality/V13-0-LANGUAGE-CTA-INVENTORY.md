## CTA inventory

Aktualnie występują m.in.: Porozmawiajmy o projekcie, Wycena strony, Zapytaj o projekt, Otwórz Live Lab, Zobacz zakres, Napisz e-mail, Opisz projekt, Otwórz projekt.

V13 docelowo ogranicza publiczny system CTA do trzech ról:
1. główne: `Wyceń projekt`;
2. kontaktowe: `Napisz do nas` / `Umów rozmowę` po uruchomieniu właściwego kanału;
3. dowodowe: `Zobacz realizacje` / `Zobacz możliwości`.

CTA kontekstowe mogą zmieniać tekst, ale nie mogą tworzyć konkurujących celów bez uzasadnienia.
