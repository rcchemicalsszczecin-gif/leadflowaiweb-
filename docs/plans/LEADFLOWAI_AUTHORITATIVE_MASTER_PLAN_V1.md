Build LeadFlowAI as the specialized Tervyxa web-production brand for designing, building, optimizing and growing professional websites and web systems.

WWW -> VISIBILITY -> CONVERSION -> INTELLIGENCE -> INTEGRATION -> CARE.

## Offer architecture
CREATE: company/service/premium sites, landing pages, e-commerce, redesign, modernization, migration, custom web development, multilingual and CMS/headless CMS where justified.

GROW: technical/on-page/local SEO, information/content architecture, structured data, AEO, GEO/AI Search, CRO, lead generation and analytics.

INTELLIGENCE: FAQ, sales, qualification, RAG and connected website chatbots.

CARE: DNS, SSL, hosting, deployment, backups, uptime/security/performance monitoring, updates and ongoing SEO/AEO/GEO work.

## UX/UI invariants
Mobile-first, strong hierarchy, clear CTA, controlled motion, usable forms, keyboard support, focus states, reduced motion, readable typography and no decoration that damages conversion/performance.

Mobile is not a scaled desktop. Navigation, density, touch targets, motion and composition must be explicitly validated on compact devices.

## SEO
Semantic HTML, metadata, canonical, sitemap, robots, redirects/statuses, internal links, breadcrumbs, hreflang when relevant, image SEO, crawl/index controls and truthful structured data.

V14 preserves the V13 URL/search-intent architecture. Search redesign/expansion based on real post-release data belongs to a later V15 Search Master Plan.

## AEO
Answer-first structure, direct definitions, descriptive headings, legitimate visible FAQs and concise answers followed by depth.

## GEO / AI Search
Entity clarity, consistent public truth, machine-readable organization/service facts, useful original information, clear attribution and source-friendly page structure. Do not promise guaranteed placement, recommendation or citation in generative systems.

## Structured data
Use Organization, WebSite, WebPage, Service, BreadcrumbList, Article, FAQPage and other types only where semantically valid and consistent with visible content. No schema spam and no invented dates/facts.

## CRO / lead system
Build deliberate CTA architecture, low-friction quote/contact flows, trust/evidence placement and mobile conversion. Current Owner decision keeps online form delivery disabled; direct e-mail through `kontakt@leadflowai.pl` is active.

The V14 brief builder may remain frontend-only and create a prepared e-mail message. It must not imply server-side lead delivery.

## Chatbot
Chatbots remain part of the commercial offer. The public LeadFlowAI chatbot widget remains disabled until a separately authorized activation stage.

Dormant code may remain only if current contracts prevent accidental public activation and the future API/runtime boundary remains explicit.

## Analytics/privacy
Plan for Search Console, Bing Webmaster Tools, conversion/event analytics and consent-aware measurement appropriate to the deployment and legal basis. Runtime analytics/consent changes require a separate reviewed stage.

## Accessibility/security/performance
Required:
- semantic landmarks/headings;
- keyboard/focus support;
- mobile navigation;
- 44px-class touch targets for key compact controls;
- labels/ARIA where semantics require them;
- contrast;
- reduced-motion complete fallback;
- no essential WebGL dependency;
- TLS/edge security at the deployment layer;
- server-side validation/rate limiting only when server functionality exists;
- dependency hygiene and secret management;
- minimal unnecessary client JS;
- controlled CSS ownership;
- optimized static assets;
- aggregate and route-level performance regression budgets;
- representative Chromium and Firefox QA.
