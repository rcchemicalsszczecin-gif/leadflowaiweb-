WWW -> VISIBILITY -> CONVERSION -> INTELLIGENCE -> INTEGRATION -> CARE.

## Offer architecture
CREATE: company/service/premium sites, landing pages, e-commerce, redesign, modernization, migration, custom web development, multilingual and CMS/headless CMS where justified.

GROW: technical/on-page/local SEO, information/content architecture, structured data, AEO, GEO/AI Search, CRO, lead generation and analytics.

INTELLIGENCE: FAQ, sales, qualification, RAG and connected website chatbots.

CONNECT: forms, CRM, e-mail, calendars, booking, payments, APIs, webhooks and n8n/Make/custom backend where directly connected to web workflows.

CARE: DNS, SSL, hosting, deployment, backups, uptime/security/performance monitoring, updates and ongoing SEO/AEO/GEO work.

## Homepage architecture
Header -> WWW-first hero -> immediate value/proof -> CREATE -> DISCOVER/GROW -> CONVERT -> INTELLIGENCE -> CONNECT -> modernization/audit -> process -> quality/technology -> real portfolio when available -> CARE -> FAQ -> CTA -> legal footer.

## UX/UI invariants
Mobile-first, strong hierarchy, clear CTA, controlled motion, usable forms, keyboard support, focus states, reduced motion, readable typography and no decoration that damages conversion/performance.

## Approved design

Visual design is frozen after V9.2 except for corrections permitted by V10 responsive/performance governance.

## SEO
Semantic HTML, metadata, canonical, sitemap, robots, redirects/statuses, internal links, breadcrumbs, hreflang when relevant, image SEO, crawl/index controls and truthful structured data.

## AEO
Answer-first structure, direct definitions, descriptive headings, legitimate FAQs and concise answers followed by depth.

## GEO / AI Search
Entity clarity, consistent public truth, machine-readable organization/service facts, useful original information, clear attribution and source-friendly page structure. Do not promise guaranteed placement in generative systems.

## Structured data
Use Organization, WebSite, WebPage, Service, BreadcrumbList, Article and other types only where semantically valid. No schema spam.

## CRO / lead system
Build deliberate CTA architecture, low-friction quote/contact flows, trust/evidence placement, mobile conversion and measurable events. Current Owner decision keeps online form delivery disabled; direct e-mail through `kontakt@leadflowai.pl` is active.

## Chatbot
Chatbots support the site rather than obstruct it. Advanced tiers may include qualification, RAG and connected workflows. Current Owner decision keeps the public LeadFlowAI chatbot widget disabled until a separately authorized activation stage.

## Analytics/privacy
Plan for Search Console, Bing Webmaster Tools, conversion/event analytics and consent-aware measurement appropriate to the deployment and legal basis.

## Accessibility/security/performance
Semantic landmarks, keyboard/focus, labels, contrast, alt/reduced-motion/ARIA discipline; TLS, secure headers, server-side validation, rate limiting, anti-spam, dependency hygiene and secrets management; minimal client JS, optimized images/fonts, caching/code splitting and Core Web Vitals monitoring.
